# Tiebreak Round Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When exactly 5 players are alive and exactly 2 players tie for the worst answer (same max delta), skip elimination for that round, immediately create a restricted tiebreak round for only those 2 players, show the other 3 a waiting screen with a countdown, and eliminate the clear loser after the tiebreak closes — leaving 4 players to trigger the existing bracket.

**Architecture:** Add `tiebreak_players JSONB` column to `rounds` table. The close route detects the 5-alive / 2-tied condition, skips elimination, creates the tiebreak round in the same request, and returns `tiebreakNeeded: true` with the new round data. The answer route blocks submissions from non-tiebreak players. GameScreen handles a new `tiebreak:started` broadcast and a new `'tiebreak-waiting'` UI phase. A new `TiebreakWaitingScreen` component displays the holding message and countdown for the 3 safe players. If the tiebreak also ties, another tiebreak round is created and the cycle repeats. When the tiebreak resolves, the existing `generateBracketForSession` helper (extracted from the close route) runs as normal.

**Tech Stack:** Next.js 15 App Router, TypeScript, Supabase Postgres + Realtime broadcasts, Tailwind CSS v4

```typescript
async function generateBracketForSession(
  supabase: ReturnType<typeof createServerClient>,
  sessionId: string
): Promise<import('@/types').BracketState | null> {
  const { data: alivePlayers } = await supabase
    .from('players')
    .select('id, nickname')
    .eq('session_id', sessionId)
    .eq('is_alive', true)

  const aliveList = (alivePlayers ?? []) as Array<{ id: string; nickname: string }>
  if (aliveList.length !== 4) return null

  const { data: roundsWithAnswers } = await supabase
    .from('rounds')
    .select('question_id, answers(player_id, value), questions(answer)')
    .eq('session_id', sessionId)
    .eq('status', 'closed')

  const totalDelta: Record<string, number> = {}
  for (const p of aliveList) totalDelta[p.id] = 0

  for (const r of (roundsWithAnswers ?? []) as any[]) {
    const correct = r.questions?.answer ?? 0
    const answeredIds = new Set((r.answers ?? []).map((a: any) => a.player_id as string))
    for (const ans of r.answers ?? []) {
      totalDelta[ans.player_id] = (totalDelta[ans.player_id] ?? 0) + Math.abs(ans.value - correct)
    }
    for (const p of aliveList) {
      if (!answeredIds.has(p.id)) {
        totalDelta[p.id] = (totalDelta[p.id] ?? 0) + 999999
      }
    }
  }

  const ranked = [...aliveList].sort((a, b) => (totalDelta[a.id] ?? 0) - (totalDelta[b.id] ?? 0))
  return {
    sf1: { p1id: ranked[0].id, p1: ranked[0].nickname, p2id: ranked[3].id, p2: ranked[3].nickname, wins: [0, 0] },
    sf2: { p1id: ranked[1].id, p1: ranked[1].nickname, p2id: ranked[2].id, p2: ranked[2].nickname, wins: [0, 0] },
    currentSF: 1,
    finalists: [],
  }
}
```

```typescript
let tiebreakNeeded = false
let tiebreakRoundId: string | null = null
let tiebreakQuestion: { id: string; text: string; timeLimit: number; category: string } | null = null
let tiebreakPlayerIds: string[] | null = null
let tiebreakStartedAt: string | null = null

const isTiebreakRound = Array.isArray((round as any).tiebreak_players)

if (
  !isTiebreakRound &&
  (session as any).phase === 'normal' &&
  activeList.length === 5 &&
  eliminated.length === 2
) {
  tiebreakNeeded = true
  skippedElimination = true

  // Pick a fresh question for the tiebreak
  const { data: usedRows } = await supabase
    .from('rounds')
    .select('question_id')
    .eq('session_id', session.id)
  const usedIds = (usedRows ?? []).map((r: any) => r.question_id as string)

  const category = (session as any).category ?? 'all'
  let questionQuery = supabase.from('questions').select('id, text, answer, category, time_limit')
  if (category !== 'all') questionQuery = questionQuery.eq('category', category)
  const { data: questionRows } = await questionQuery
  const available = ((questionRows ?? []) as any[]).filter((q: any) => !usedIds.includes(q.id))

  if (available.length === 0) {
    return NextResponse.json({ error: 'No questions available for tiebreak' }, { status: 500 })
  }
  const tbQuestion = available[Math.floor(Math.random() * available.length)]

  const { data: latestRoundRows } = await supabase
    .from('rounds')
    .select('round_number')
    .eq('session_id', session.id)
    .order('round_number', { ascending: false })
    .limit(1)
  const latestRoundNumber = ((latestRoundRows ?? [])[0] as any)?.round_number ?? 0

  const { data: newRound, error: newRoundError } = await supabase
    .from('rounds')
    .insert({
      session_id: session.id,
      question_id: tbQuestion.id,
      round_number: latestRoundNumber + 1,
      tiebreak_players: [eliminated[0].playerId, eliminated[1].playerId],
    })
    .select('id, started_at')
    .single()

  if (newRoundError || !newRound) {
    return NextResponse.json({ error: 'Failed to create tiebreak round' }, { status: 500 })
  }

  tiebreakRoundId = (newRound as any).id
  tiebreakStartedAt = (newRound as any).started_at
  tiebreakPlayerIds = [eliminated[0].playerId, eliminated[1].playerId]
  tiebreakQuestion = {
    id: tbQuestion.id,
    text: tbQuestion.text,
    timeLimit: tbQuestion.time_limit,
    category: tbQuestion.category,
  }
}
// --- END TIEBREAK DETECTION ---
```

```typescript
if (isTiebreakRound) {
  const tbPlayers = (round as any).tiebreak_players as string[]
  const p1 = answers.find(a => a.playerId === tbPlayers[0])
  const p2 = answers.find(a => a.playerId === tbPlayers[1])

  if (p1delta === p2delta) {

    const { data: usedRows2 } = await supabase
      .from('rounds').select('question_id').eq('session_id', session.id)
    const usedIds2 = (usedRows2 ?? []).map((r: any) => r.question_id as string)

    const category2 = (session as any).category ?? 'all'

    if (avail2.length === 0) {

    const tbQ2 = avail2[Math.floor(Math.random() * avail2.length)]

    const { data: latestRows2 } = await supabase
      .from('rounds').select('round_number').eq('session_id', session.id)
      .order('round_number', { ascending: false }).limit(1)
    const latestNum2 = ((latestRows2 ?? [])[0] as any)?.round_number ?? 0

    const { data: newRound2, error: newRoundErr2 } = await supabase
      .from('rounds')
      .insert({
        session_id: session.id,
        question_id: tbQ2.id,
        round_number: latestNum2 + 1,
        tiebreak_players: tbPlayers,
      })
      .select('id, started_at')
      .single()

    if (newRoundErr2 || !newRound2) {
      return NextResponse.json({ error: 'Failed to create tiebreak round' }, { status: 500 })
    }

    return NextResponse.json({
      correctAnswer,
      answers,
      eliminated: [],
      winner: null,
      gameOver: false,
      wasAlreadyClosed: false,
      bracketReady: false,
      bracket: null,
      tiebreakNeeded: true,
      tiebreakRoundId: (newRound2 as any).id,
      tiebreakQuestion: { id: tbQ2.id, text: tbQ2.text, timeLimit: tbQ2.time_limit, category: tbQ2.category },
      tiebreakPlayerIds: tbPlayers,
      tiebreakStartedAt: (newRound2 as any).started_at,
    })
  }

  // Resolved — eliminate the loser
  const loserId = p1delta > p2delta ? tbPlayers[0] : tbPlayers[1]
  await supabase.from('players').update({ is_alive: false }).in('id', [loserId])

  const { count: aliveAfterTB } = await supabase
    .from('players')
    .select('id', { count: 'exact', head: true })
    .eq('session_id', session.id)
    .eq('is_alive', true)

  let bracketReadyTB = false

  if ((aliveAfterTB ?? 0) === 4) {

    if (bracketTB) {
      const { error: bErr } = await supabase
        .from('sessions')
        .update({ phase: 'semifinal', bracket: bracketTB })
        .eq('id', session.id)
      if (!bErr) bracketReadyTB = true
      else bracketTB = null
    }
  }

  const loserEntry = answers.find(a => a.playerId === loserId)
  return NextResponse.json({
    correctAnswer,
    answers,
    eliminated: loserEntry ? [{ playerId: loserEntry.playerId, nickname: loserEntry.nickname }] : [],
    winner: null,
    gameOver: false,
    wasAlreadyClosed: false,
    bracketReady: bracketReadyTB,
    bracket: bracketTB,
    tiebreakNeeded: false,
    tiebreakRoundId: null,
    tiebreakQuestion: null,
    tiebreakPlayerIds: null,
    tiebreakStartedAt: null,
  })
}
```

```typescript
'use client'

import { useEffect, useState } from 'react'

interface Props {
  roundNumber: number
  deadlineMs: number   // epoch ms when the tiebreak round expires
}

export function TiebreakWaitingScreen({ roundNumber, deadlineMs }: Props) {
  const [secondsLeft, setSecondsLeft] = useState(() =>
    Math.max(0, Math.ceil((deadlineMs - Date.now()) / 1000))
  )

  useEffect(() => {
    const interval = setInterval(() => {
      setSecondsLeft(Math.max(0, Math.ceil((deadlineMs - Date.now()) / 1000)))
    }, 500)
    return () => clearInterval(interval)
  }, [deadlineMs])

  return (
    <div className="flex flex-col items-center justify-center min-h-dvh p-4 text-center">
      <div className="w-full max-w-sm flex flex-col items-center gap-6">
        <div className="text-6xl">⚔️</div>
        <div className="bg-white rounded-2xl shadow-md px-6 py-5 w-full">
          <div className="text-lg font-black text-gray-900">Tiebreak in progress</div>
          <div className="text-sm text-gray-500 mt-1">
            Don&apos;t worry — you&apos;ve made it to the semi-finals!
          </div>
        </div>
        <div className="bg-white/10 rounded-xl px-6 py-4 w-full">
          <div className="text-white/70 text-sm mb-1">Time remaining</div>
          <div className="text-4xl font-black text-white tabular-nums">
            {secondsLeft}s
          </div>
        </div>
        <p className="text-white/60 text-sm">Round {roundNumber} · Tiebreak</p>
      </div>
    </div>
  )
}
```

```typescript
  channelRef.current?.send({
    type: 'broadcast',
    event: 'tiebreak:started',
    payload: {
      roundId: pending.roundId,
      question: pending.question,
      startedAt: pending.startedAt,
      playerIds: pending.playerIds,
    },
  })
  return
}
// --- END PENDING TIEBREAK ---
```

## State Flow Reference

```
Normal round closes (5 alive, 2 tied for max delta)
  → close route: skip elimination, create tiebreak round, return tiebreakNeeded:true
  → host broadcasts round:closed WITH tiebreak payload
  → all clients: phase='reveal', pendingTiebreak stored in state
  → 5s reveal auto-advance (host):
      → host broadcasts tiebreak:started
      → tiebreak players (2): phase='answering', roundId=tiebreakRoundId
      → other 3: phase='tiebreak-waiting', countdown visible
  → tiebreak round closes:
      → if still tied: another tiebreak round created → cycle repeats
      → if resolved: eliminate loser → aliveCount=4 → bracket generated
          → bracketReady:true → host broadcasts bracket:ready
          → all clients: phase='bracket' → existing bracket flow
```

---

## Edge Cases

| Scenario | Handling |
|---|---|
| Both tiebreak players don't answer | Both get MAX delta → equal → another tiebreak round |
| One tiebreak player disconnects | They get MAX delta → the other wins |
| Host is one of the 2 tiebreak players | Host in `answering` phase, closes round on timer as normal |
| Resurrection during tiebreak | `/rounds/next` is not called for tiebreak rounds → no resurrection during tiebreak |
